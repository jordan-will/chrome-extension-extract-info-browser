# Tab Info Grabber (Chrome Extension)

A lightweight and straightforward Google Chrome extension that extracts the **title** and **URL** of the currently active browser tab with a single click.

## Features

- **Instant Extraction:** Retrieves the current page's title and full URL immediately upon clicking the extension icon.
- **Privacy First:** Runs 100% locally in your browser. No browsing data is stored or sent to external servers.
- **Manifest V3:** Built using the latest Chrome Extension architecture for optimal performance and security.
